Fonts:
- Poppins

HOW TO OPEN:
1. Extract lm_academy_website.zip.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html.
4. Right-click index.html and choose "Open with Live Server" (if Live Server is installed), or open index.html in a browser.

IMPORTANT BEFORE PUBLISHING:
- Replace sample course content with confirmed LM Academy programmes.
- Add the official phone number, email and campus address on contact.html.
- Add real campus/student photos in the img folder.
- The contact form is a front-end demo only; connect it to a form service or backend to receive submissions.
- Google Fonts requires an internet connection. Add licensed font files locally if needed.
